# Sync conflicts

When the same note is edited on two devices before they sync, Quillbox keeps both versions.
The version that syncs second is saved as a separate note with "(conflicted copy)" added to its title.
Quillbox does not merge conflicting edits automatically.
To combine them, open both notes side by side, copy the changes you want to keep, then delete the conflicted copy.
Deleted notes stay in Trash for 30 days before they are removed permanently.
